# Thumbly Space for Mac — downloads

This repository only holds the macOS app's releases (`.dmg` / `.zip`).
There is no source code here.

Download the latest version from **[Releases](https://github.com/beiryu/thumbly-space-releases/releases/latest)**
or from the Thumbly Space website's Download page.

- Apple Silicon: `zr8m-<version>-arm64.dmg`
- Intel: `zr8m-<version>-x64.dmg`

Requires macOS 14.2 or later. The installed app is named **zr8m**.
